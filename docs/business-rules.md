# Reguły biznesowe

Samodzielna aplikacja Expo React Native będąca prototypem konsumenckiego Benefitly.

Nie dodajemy reguł, których nie potwierdza kod, istniejąca dokumentacja lub uzgodniony kontrakt. Dla tego komponentu należy dopisać właścicieli, role i krytyczne invariants, gdy zostaną potwierdzone.
