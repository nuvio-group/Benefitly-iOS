# Konfiguracja

Konfiguracja środowiskowa należy do Coolify/Vaulta i nie jest zapisywana w repozytorium.

- środowiska logiczne: `dev`, `prod`;
- wartości sekretów, tokeny i certyfikaty: poza Git;
- nazwy zmiennych i ich przeznaczenie dopisywać po potwierdzeniu w konfiguracji deploymentu;
- konfiguracje builda opisane w plikach projektu pozostają źródłem prawdy dla kompilacji.
