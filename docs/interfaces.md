# Interfejsy

Potwierdzone punkty styku wynikają z aktualnej struktury repozytorium i jego dokumentów. Kontrakty API, webhooków i integracji zewnętrznych, których nie ma w kodzie lub dokumentacji, są **do uzupełnienia** przed użyciem produkcyjnym.

- zależność główna: loyalty;
- szczegółowe ścieżki i schematy: do uzupełnienia w tym repozytorium;
- nie traktować prototypów i wymagań jako wdrożonych kontraktów.
