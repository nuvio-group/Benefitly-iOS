# Architektura

React Native, Expo, TypeScript, Zustand, React Navigation i Reanimated; moduły obejmują Home, Rewards, Card, Discover, Profile i przełączanie merchantów.

## Granice

Repozytorium opisuje komponent `benefitly-ios`. Integracje z innymi komponentami są zależnościami, nie własnością tego repozytorium. Elementy niewidoczne w kodzie pozostają oznaczone jako „do uzupełnienia”.
