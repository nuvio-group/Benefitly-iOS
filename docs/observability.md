# Observability

Nie deklarujemy dashboardu Grafany, dopóki jego identyfikator i źródła danych nie są potwierdzone. Logi muszą zawierać bezpieczny kontekst operacji i nie mogą ujawniać sekretów, PII ani pełnych payloadów.

Do uzupełnienia dla komponentu `benefitly-ios`: healthcheck, poziomy logowania, korelacja żądań, metryki i alarmy.
